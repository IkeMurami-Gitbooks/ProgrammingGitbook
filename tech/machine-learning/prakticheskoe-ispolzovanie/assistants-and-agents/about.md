## Базовые принципы использования агентов

* Не перекладывать на агенты размышления (подумать над задачей все же на нас, агент помогает)
* Проверяем за агентом, не доверяем безусловно
* Обдумывать вопросы агенту (так как все попадает в контекст / память)
* Не теряем наши навыки: продолжаем что-то делать вручную (иначе не узнаем, что агент стал делать хуже задачу)

### Нюансы

* ИИ свой контекст считает за источник правды
  * Если ИИ не поправлять, то он будет ошибаться (так как ошибки лягут в контекст)
  * Как исправляться: упаковывать контекст периодически (тем самым убираем лишнее не по теме) или очищать контекст
* Работаем по циклу:
  * Plan (просим прописать план решения)
  * Review (проверяем адекватность плана, можно другой моделькой или агентом)
  * Implement
  * Iterate
* Можно спавнить агентов, которые будут смотреть на проблему с разных сторон (например, один защищает мнение, другой челленджит, третий ресерчит)
* Возможности дополнительные у агентов:
  * Hooks: это триггер, получаем гарантирую выполнения действия
  * Skills: это инструкции "как делать", учит модель выполнять действия
* У агентов может быть память долговременная (и между сессиями):
  * "Запомни как делать что-то (из сессии)". И он запомнит
  * Так же можно создавать скиллы
